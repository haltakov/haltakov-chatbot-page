How to use ML to search photos by natural language? 🗣️🏞️

I created a small project on GitHub to show you how you can use OpenAI's CLIP neural network to do that!



Let's see how we can find photos for the phrase "a car driving in the woods".

A thread 👇 \n\n---\n\n I first fetch 100 images from the Unsplash API for the keyword "car".

As you can see from the results, it returns various images of cars ("car woods" isn't much better).  \n\n---\n\n Then, I used OpenAI's CLIP to process all 100 images as well as the phrase "a car driving in the woods".

The amazing thing about CLIP is that it then transforms both images and text in the same (latent) space where we can compare them!
