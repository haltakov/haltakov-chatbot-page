Client or server side analytics? I've been playing around with different analytics options on my blog - @Netlify on the server and @PlausibleHQ  on the client side. The results from the last 7 days are quite different. Why? How are the two approaches different? A Thread (1/8)  \n\n---\n\n Server side analytics have several native advantages: 
- No overhead on your website, because no external resources are loaded 
- Not affected by content blockers 
- Can track resources other than web pages, like images or redirects
- Show resources that could not be found (2/8) \n\n---\n\n Client side analytics on the other hand:
- Can capture more data about the user, like device size, browser and OS 
- Better track user behavior, like time spent on each page 
- Provide real-time feedback about visitors
- Usually easier to setup (3/8) \n\n---\n\n The difference in page views is interesting - the server side tool shows much more views across all pages in my blog. I think this is because the pages are accessed many times from automated systems that don't run JavaScript and are therefore not counted on the client side. (4/8) \n\n---\n\n This happens when you post a link on Twitter or WhatsApp for example, because their websites or clients then make a request to fetch the metadata of the page and display a card preview. Therefore, it counts on the server, but not on the client side. (5/8) \n\n---\n\n A perfect example is the draft article, which I only sent per WhatsApp to my wife for proof reading. The difference there is just 2 views (I guess one preview each on my and on her phone). I sent all other links to several people and posted them on Twitter and Reddit. (6/8) \n\n---\n\n You can also somewhat see this effect in the referrers. The server side tool counted many hits from a RSS reader and Google Translate (my parents in law reading my blog in Bulgarian 😂). The preview requests from Twitter and WhatsApp are probably counted as direct traffic. (7/8)  \n\n---\n\n In conclusion, I think client side analytics more realistically count the number of people reading my blog (even if not many). However, there are cases that can be captured only on the server side (for example Google Translate). I guess I will stick with both for now... 😃 (8/8) \n\n---\n\n This project sounds cool as well!
