# UnsubPost

Post to all major social platforms with one TypeScript library: X, YouTube, Instagram, TikTok, Facebook, LinkedIn, Pinterest. No subscriptions. No SaaS. Just clean code.

## Description

UnsubPost is a developer-first TypeScript library that lets you publish to multiple social media platforms with a single interface. It includes a powerful OAuth helper tool, plug-and-play N8N nodes, and complete source code ownership. One-time payment. Lifetime access.

## Background

I'm getting tired of the SaaS model. Even tools that don't have real ongoing costs require a subscription. What I want to try instead is to sell my knowledge and work for a one-time fee and let the user own it and do whatever they want with it.

## Tech

- TypeScript library (NPM package)
- Express.js and Next.js servers that you can self-host
- N8N nodes that you can use in your own N8N instance
