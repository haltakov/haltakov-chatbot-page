# Leoline

An interactive story game largely vibe coded for the [2025 Vibe Coding Game Jam](https://jam.pieter.com/) by [@levelsio](https://x.com/levelsio). You can play [VibeLegends here](https://vibelegends.com/).

## Description

Build partially on top of the tech I developed for [Leoline](https://leoline.fun). The 3D world you can fly through to discover new stories was pretty much all vibe coded with Cursor and Claude 3.7 Sonnet.
