# TS Script Boilerplate

A simple, modern and working way to create a script using TypeScript that use `import` and `export`. Take a look here: [ts-script-boilerplate](https://github.com/haltakov/ts-script-boilerplate).

## Background

There is still no LLM that can properly code a working script using TS! There are 1000 options to do it, so I was frustrated and looking for a simple and modern way to do that. I created a repo with boilerplate based on my reserach.

## Background

I wanted to learn how to build an MCP server and thought it would be a fun project to build a simple meme generator. It turned out that vibe coding it just doesn't work, so in the end read the docs and built it from scratch using the [@modelcontextprotocol/sdk](https://github.com/modelcontextprotocol/typescript-sdk) package and the Imgflip API.
