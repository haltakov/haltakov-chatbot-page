# Archived Projects

This folder contains details about my past projects that are no longer actively maintained.

- **Bnomial** – A machine learning quiz site that delivers one ML question with a detailed answer every day. Built together with [@svpino](https://x.com/svpino). [View project](https://today.bnomial.com)
- **SUBOPTIMaL** – A wiki featuring simple explanations for seemingly complicated machine learning and math terms. [View project](https://suboptimal.wiki)
- **Rescue Toadz** – A charity crypto project raising funds to support Ukraine. It used a novel Ethereum smart contract to forward all donations to **Unchain Ukraine**, incorporating gamified NFT mechanics. [View project](https://rescuetoadz.xyz)
- **AI Toadz** - AI-generated toadz from the CrypToadz collection. [View project](https://aitoadz.xyz)
