# Simple Photo Gallery

Beautiful and simple photo galleries that help you tell your story:  
[Project Page](https://github.com/haltakov/simple-photo-gallery)

## Description

**Simple Photo Gallery** is an open-source command-line tool for creating beautiful photo galleries for your website. It generates static **HTML, JS, and CSS** files, which you can **self-host anywhere**.

## Background

I built this tool because I wanted a simple way to create **custom photo galleries** from my travels to share with friends and family. Existing solutions didn't give me enough control over **photo arrangement and descriptions**, so I created my own.

What started as a personal project turned out to be useful to others—I regularly receive feedback from users who enjoy using it.

## Tech

- Built with **Python, Jinja2, and vanilla HTML/CSS/JS**
- Easily installable via `pip install simple-photo-gallery`
- Full flexibility to arrange photos, add descriptions, and customize the design

## Plans

- Keeping the **core library open-source** for self-hosting
