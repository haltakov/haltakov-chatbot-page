# Simple Muscle

Simple Muscle is an AI workout tracker for iPhone created by Vladimir Haltakov and Creafex Lab. It connects the AI assistant a person already uses to structured workout plans, logged sets, and training history.

- Canonical website: https://simplemuscle.ai/
- App Store: https://apps.apple.com/app/id6787905614
- Company: https://creafexlab.com/
- Creator: https://haltakov.com/

## What it does

- The free core iPhone tracker works offline and includes unlimited workouts and exercises, a rest timer, Live Activity, history, and charts.
- It tracks exercises, sets, reps, weight, duration, rest time, and completed sessions.
- It connects ChatGPT, Claude, OpenClaw, and other Model Context Protocol (MCP)-compatible assistants.
- An authorized assistant can create, update, archive, or delete workout plans and can read completed training history for progress analysis and plan updates.
- Completed training history is read-only to connected assistants.
- A free web dashboard and the MCP connection are available independently of the iOS subscription.
- The optional paid iOS plan adds cloud backup and continuous synchronization between the iPhone app, web dashboard, and connected assistants after its trial.

## How the assistant connection works

1. The user authorizes a compatible AI assistant.
2. The assistant creates or updates a workout plan in chat.
3. The user performs and logs the workout in the iPhone app.
4. The assistant can request the completed structured training history before suggesting changes.

Simple Muscle does not bundle a separate proprietary AI coach. It lets the user choose the assistant they already use. Connecting does not automatically upload all workout data in bulk; data is returned when the authorized assistant requests it.

Simple Muscle does not sell workout data or use it for advertising. The connected assistant's own privacy, retention, model-training, and account-control practices apply to any data it receives.
