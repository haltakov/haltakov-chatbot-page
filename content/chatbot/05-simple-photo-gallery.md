question: What is Simple Photo Gallery?
---

**Simple Photo Gallery** started as a personal tool.

I wanted to create travel photo galleries that told a story, with groups, descriptions, labels, and full control over the presentation. Existing tools like Google Photos, OneDrive, or Flickr did not give me the storytelling control I wanted.

The first version was an open-source Python CLI that generated static HTML, CSS, JavaScript, and processed images. The current [open-source version](https://github.com/SimplePhotoGallery/core) is built with TypeScript and generates responsive static galleries that people can self-host anywhere.

The newer version is a modern web app and hosted platform at [simple.photo](https://simple.photo), built with a modern TypeScript/React stack. The goal is to make beautiful story-driven galleries easy for both technical and non-technical users.

It remains one of my favorite examples of a personal need becoming a useful open-source product. I use it to create galleries from every trip and share with friends and family. Check out some of them below:
