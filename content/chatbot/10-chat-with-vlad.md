**Chat with Vlad** is the predecessor to this site.

It is a simple AI chatbot that pretends to be me. The original version used an OpenAI vector store with public information about me, including tweets, blog posts, project descriptions, and a longer personal background document.

This repo uses **chatbot-page**, a reusable package extracted from that idea. Right now it uses curated canned answers first and has a backend placeholder ready for a real LLM/RAG integration later.
