This is a chatbot-style personal website for Vladimir Haltakov. Instead of browsing a traditional portfolio, you can ask about my background, projects, research, companies, and ways to get in touch.

- Suggested questions use curated Markdown answers.
- Unknown questions can stream from the LLM/RAG backend.
- The site is built with the reusable `chatbot-page` package.
